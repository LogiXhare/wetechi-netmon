# Architecture

Status: Phase 1 skeleton — populated incrementally from Phase 2 onward.

This section will hold data-flow diagrams, sequence diagrams, and
component documentation for each of the 15 logical services described in
[Functional Requirements](../functional-requirements.md).

Until then, see the Phase 0 foundation documents for current architectural
direction:

- [Architecture Options](../architecture-options.md) — structural options
  and leanings, not yet finalized
- [Technology Options](../technology-options.md) — candidate technology
  choices per component
- [Architecture Decision Records](decisions/index.md) — the process and
  template used to formally record each decision once made

No architecture decision is binding until it exists as a numbered ADR
under `decisions/`.
